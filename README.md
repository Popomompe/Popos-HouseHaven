# Popos HouseHaven

A real estate listings website for South African properties, built with plain HTML, CSS, and JavaScript. No frameworks or libraries.

## Features

- Navigation between Home, Houses, Apartments, New Developments, Map, and Agent Profiles sections
- Property listings with price, address, photos, and the listing agent
- Agent profile cards with contact details and specialty
- Bond calculator that works out the monthly repayment from the amount, interest rate, and loan term
- Province and city dropdowns, where the city list updates when you pick a province
- Contact form
- Responsive layout for desktop, tablet, and mobile screens

## Built with

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, form handling)

## How to run

1. Download or clone this repository.
2. Open `Popos HouseHaven.html` in any web browser.

No installation is needed.

## Known limitations

This is a front-end practice project, so some parts are unfinished:

- Agent names, phone numbers, and prices are sample data.
- Property images are linked from external listing sites for demonstration only.
- The Favorites and Wishlist sections are not connected yet.
- The map is a placeholder embed.
- The sign-in and registration pop-ups are written but not linked to the menu. They store credentials in the browser, so they should not be used for real accounts.
